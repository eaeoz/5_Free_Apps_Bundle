🌟 Our Mission

5 Free Apps Bundle is a collection of open-source Windows applications designed to make everyday tasks easier. From downloading media to managing Docker containers, each tool is built with simplicity, performance, and user experience in mind.

Our mission is to provide high-quality, free software alternatives that respect your privacy and give you full control over your data. No ads, no trackers, no hidden agendas — just useful tools.

📖 Our Story

Early 2024
YouTube Downloader — v1.0.0
Electron desktop app powered by yt-dlp & FFmpeg. Download YouTube videos and audio with a format browser, playlist support, and real-time SSE progress. The first of five.
Mid 2024
Movie Downloader & Music Downloader
Movie Downloader (v1.0.6): torrent-based downloader with Letterboxd watchlist sync, multi-source search (YTS, TPB, RARBG), and a built-in video player. Music Downloader (v1.0.0): search YouTube, fetch Deezer/iTunes metadata, and download MP3s with embedded album art.
Late 2024
Command Manager & Sondakika
Command Manager (v1.0.6): SSH command manager with a GUI builder for styled command cards — runs as a Windows app or Docker container. Sondakika (v2.0.4): Turkish RSS news reader aggregating 10+ major sources (Cumhuriyet, TRT, CNN Turk, etc.) with an in-app article reader.
2025 & Beyond
Dashboard & Continuous Improvement
The live download dashboard was built to track stats, showcase the suite, and make installation a one-click experience. Ongoing releases with bug fixes, features, and refinements across all five apps.

🔧 Technology

All five applications are Electron desktop apps for Windows, each following a consistent architecture: an Express.js backend serves a vanilla JavaScript frontend inside an Electron frameless window with system tray support.

Key technologies: Electron 28+ for desktop shells, Express.js backends, electron-builder for packaging (NSIS installer + portable variants), yt-dlp + FFmpeg for media processing, WebTorrent for torrents, ssh2 for remote connections, Docker for containerized deployments, and GitHub Actions for CI/CD. The dashboard is pure HTML/CSS/JS — no frameworks, no bloat.

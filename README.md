## Usage

Open [`index.html`](index.html) in any browser — no server needed. The dashboard fetches live data from:

```
https://raw.githubusercontent.com/eaeoz/app-stats/main/public/releases.json
```

Each repo card displays:

- Owner avatar & name
- App icon with accent color
- **Total downloads** across all releases
- **Release count** (unique tags with `.exe` assets)
- Star count from GitHub
- One-click install command
- Latest `.exe` assets (Setup + Portable) with file size & download count per row
- Link to repository

## Editing

Edit `index.html`:

- **`REPOS`** array — add/remove `"owner/repo"` entries
- **`META`** map — add matching entry with `label`, `icon` (SVG), `accent` color, `cmd` (install command)
- Repos with no `.exe` assets show "No executables found"
